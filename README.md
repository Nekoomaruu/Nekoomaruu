## About Me

I have been around programming for roughly five years, and most of that time has been spent
deep inside **Lua / Luau scripting**, **Discord bot development**, and **community management**.

I enjoy building tools that genuinely help people — automation for Roblox workflows, backend
services that keep community bots online, and small utilities that remove friction for users.

My long-term goal is to grow an active community, ship a full suite of bots for it, and open
source a good portion of my work so other developers can learn from it.

## Engineering Philosophy

| Principle | What it means to me |
| :-- | :-- |
| **Clean Code** | Readable today, maintainable a year from now. |
| **Simple Solutions** | The smallest thing that solves the real problem wins. |
| **User Experience First** | A tool nobody enjoys using is a tool nobody uses. |
| **Keep Learning** | Every project should teach me something new. |
| **Build Useful Things** | Utility over novelty, always. |
| **Publish and Share** | Ship it, document it, let others learn from it. |
