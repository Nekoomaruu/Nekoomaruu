<!-- ============================ ABOUT ME ============================ -->
## About Me

I have been writing code for about five years, and most of that time has been spent deep inside
**Lua / Luau scripting**, **Discord bot development**, and **backend services** that keep communities running.

I like tools that quietly do their job: automation for Roblox workflows, bots that never need babysitting,
and small utilities that remove friction for real users. Most of my work starts as a problem inside a
community I actually manage, which keeps me honest about what is worth building.

My long term goal is to grow an active community, ship a complete suite of bots for it, and open source
a good portion of that work so other developers can read it, break it, and learn from it.

## Engineering Philosophy

| Principle | What it means to me |
| :-- | :-- |
| **Clean Code** | Readable today, maintainable a year from now. |
| **Simple Solutions** | The smallest thing that solves the real problem wins. |
| **User Experience First** | A tool nobody enjoys using is a tool nobody uses. |
| **Ship, Then Refine** | Working and shipped beats perfect and unreleased. |
